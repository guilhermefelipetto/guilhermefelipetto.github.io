MT5 LLM Agent

Python FastAPI OpenAI MetaTrader 5 GARCH HAR-RV Quant Finance LLM Agent

O MT5 LLM Agent é um agente de trading stateful que utiliza LLMs para tomar decisões em tempo real no MetaTrader 5. A cada ANALYSIS_INTERVAL segundos, o pipeline coleta dados multi-timeframe, computa indicadores técnicos, testes estatísticos e modelos de volatilidade (GARCH/HAR-RV), injeta o estado da posição aberta no prompt e consulta a OpenAI — que responde com uma ação: OPEN_LONG, OPEN_SHORT, HOLD, CLOSE (sair antes de SL/TP) ou TIGHTEN_STOP (apertar SL para travar lucro). The MT5 LLM Agent is a stateful trading agent that uses LLMs for real-time decisions on MetaTrader 5. Every ANALYSIS_INTERVAL seconds, the pipeline collects multi-timeframe data, computes technical indicators, statistical tests, and volatility models (GARCH/HAR-RV), injects the open position state into the prompt, and queries OpenAI — which responds with an action: OPEN_LONG, OPEN_SHORT, HOLD, CLOSE (exit before SL/TP), or TIGHTEN_STOP (tighten SL to lock profit).

Como funcionaHow it works

O agente combina três camadas: (i) extração de features a partir de múltiplos timeframes (RSI, MACD, ATR, Bollinger, EMA), além de testes estatísticos (ADF, Ljung-Box, Hurst, VRT) e estimadores de volatilidade plugáveis (GARCH(1,1), HAR-RV de Corsi ou ATR); (ii) decisão via LLM usando um prompt builder hierárquico que injeta o contexto técnico, o estado da posição aberta e o histórico recente; (iii) gestão de risco com sizing dinâmico (confiança × volatilidade inversa), guardrails state-aware, circuit breakers de drawdown diário e perdas consecutivas. The agent combines three layers: (i) feature extraction from multiple timeframes (RSI, MACD, ATR, Bollinger, EMA), plus statistical tests (ADF, Ljung-Box, Hurst, VRT) and pluggable volatility estimators (GARCH(1,1), Corsi's HAR-RV, or ATR); (ii) LLM decision via a hierarchical prompt builder that injects technical context, open position state, and recent history; (iii) risk management with dynamic sizing (confidence × inverse volatility), state-aware guardrails, daily drawdown circuit breakers and consecutive-loss limits.

Um Expert Advisor em MQL5 roda no MetaTrader 5 e consulta o servidor FastAPI local via WebRequest a cada tick. A fonte de dados é configurável: yfinance por padrão, ou o próprio broker via mt5linux (bridge Python no Wine). An MQL5 Expert Advisor runs on MetaTrader 5 and queries the local FastAPI server via WebRequest on every tick. The data source is configurable: yfinance by default, or the broker itself via mt5linux (Python bridge in Wine).

MotivaçãoMotivation

O projeto explora se um LLM, devidamente contextualizado com features quantitativas e estado de carteira, consegue tomar decisões úteis em mercados intradiários — tratando o modelo de linguagem como um policy de alta abstração sobre features estatísticas, ao invés de tentar prever preço diretamente. Toda a infraestrutura ao redor (sizing, circuit breakers, logging por MODEL_VERSION) existe para tornar a hipótese testável de forma honesta, com lifecycle real de trades e simulação post-hoc para isolar a contribuição do LLM. The project explores whether an LLM, properly contextualized with quantitative features and portfolio state, can make useful decisions in intraday markets — treating the language model as a high-level policy over statistical features, rather than trying to predict price directly. All the surrounding infrastructure (sizing, circuit breakers, MODEL_VERSION-stamped logging) exists to make the hypothesis honestly testable, with real trade lifecycle data and post-hoc simulation isolating the LLM's contribution.
