DirTree

Python 3.12+ PyQt5 GUI Desktop Tema Claro/Escuro MIT License Open Source

O DirTree é uma aplicação desktop construída em Python com PyQt5 para gerar representações textuais de estruturas de diretórios de forma rápida, personalizável e com preview em tempo real. É útil para documentar projetos em README.md, artigos e apresentações sem depender de comandos de terminal cada vez mais complexos. A interface oferece filtros, ordenação independente para raiz e subdiretórios, tema claro/escuro e cópia direta para a área de transferência. DirTree is a desktop application built in Python with PyQt5 to generate textual representations of directory structures quickly, with rich customization and real-time preview. It is useful for documenting projects in README.md files, articles, and presentations without resorting to ever-more-complex shell commands. The interface offers filters, independent sorting for root and subdirectories, light/dark themes, and one-click copy to the clipboard.

Filtros e ordenaçãoFilters and sorting

Filtros disponíveisAvailable filters

FiltroFilter DescriçãoDescription
Ignorar pastasIgnore folders Exclui diretórios da listagem (ex.: __pycache__, .git, node_modules).Excludes directories from the listing (e.g. __pycache__, .git, node_modules).
Ignorar arquivosIgnore files Remove arquivos específicos da árvore (ex.: .DS_Store).Removes specific files from the tree (e.g. .DS_Store).
Ignorar extensõesIgnore extensions Oculta arquivos por extensão (.log, .tmp, .pyc).Hides files by extension (.log, .tmp, .pyc).
Sempre incluirAlways include Garante que certos arquivos ou pastas apareçam mesmo se baterem com algum filtro de exclusão (overrides).Ensures certain files or folders are shown even if they match an exclusion filter (overrides).

MotivaçãoMotivation

Desenvolvi o DirTree para aprofundar meus conhecimentos em interfaces gráficas desktop com PyQt5 e em manipulação de caminhos de arquivos com a stdlib do Python. O objetivo prático era resolver um problema recorrente meu — gerar árvores de diretório para documentação — com mais controle e menos atrito do que uma sequência de comandos de terminal. O resultado é uma ferramenta que eu mesmo uso para documentar os meus repositórios (inclusive este). I built DirTree to deepen my knowledge of desktop GUI development with PyQt5 and file-path manipulation using Python's standard library. The practical goal was to solve a recurring problem of mine — generating directory trees for documentation — with more control and less friction than a chain of shell commands. The result is a tool I use myself to document my own repositories (including this one).
