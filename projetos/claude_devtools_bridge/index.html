claude-devtools-bridge

JavaScript Node.js Model Context Protocol Chrome Extension (MV3) Chrome DevTools Protocol WebSocket

Uma ponte que dá ao Claude Code acesso ao Chrome DevTools Protocol por meio de uma extensão. Funciona no Chrome do dia a dia, sem precisar lançá-lo com --remote-debugging-port, em qualquer projeto onde o Claude Code for usado. Com ela o agente consegue ler erros do console, tirar screenshots, navegar, preencher formulários e inspecionar requisições da aba escolhida. A bridge that gives Claude Code access to the Chrome DevTools Protocol through an extension. It works in your everyday Chrome, without launching it with --remote-debugging-port, in any project where Claude Code is used. With it the agent can read console errors, take screenshots, navigate, fill in forms and inspect requests on the chosen tab.

InstalaçãoSetup

$ npm install
$ claude mcp add devtools-bridge --scope user -- node "$(pwd)/mcp-server/index.js"
# carregue a pasta extension/ em chrome://extensions (modo desenvolvedor)load the extension/ folder in chrome://extensions (developer mode)
$ npm start

Com o bridge rodando, basta clicar no ícone da extensão na aba desejada e em Attach to this tab. As ferramentas mcp__devtools-bridge__browser_* ficam disponíveis no Claude Code. With the bridge running, click the extension icon on the tab you want and then Attach to this tab. The mcp__devtools-bridge__browser_* tools become available in Claude Code.

SegurançaSecurity

  • O bridge escuta apenas em 127.0.0.1, sem exposição na rede.The bridge listens only on 127.0.0.1, with no network exposure.
  • Não há autenticação: assume que só processos locais se conectam. Não use em máquinas compartilhadas.There is no authentication: it assumes only local processes connect. Don't use it on shared machines.
  • A extensão só age depois que o usuário clica em Attach manualmente, e o Chrome mostra a barra amarela de depuração enquanto ela está anexada.The extension only acts after the user manually clicks Attach, and Chrome shows the yellow debugging bar while it is attached.
